100% local · Apple silicon

Bilingual subtitles for your
local videos — offline, on your Mac.

Subtitle Anywhere extracts audio with FFmpeg, transcribes it with MLX Whisper, and writes bilingual .srt files for IINA, VLC, mpv, or Plex. No cloud, no API keys, no browser extension.

Get started → See the web UI View source
install 
# macOS, Python 3.10+
brew install uv ffmpeg
uv sync
uv run python server/server.py ~/Videos/*.mp4 --source-lang eng --target-lang zho

Local-only

Inference runs entirely on your machine. No telemetry, no cloud upload, no API keys. Your videos never leave your disk.

MLX on Apple GPU

Whisper transcription and Qwen translation run on the Apple GPU via MLX. A 28-second encoder window keeps the pipeline efficient on M1/M2/M3.

Bilingual SRT, side-by-side

Every cue carries the source line and the translation, with one sentence per screen by default. Works in IINA, VLC, mpv, and Plex.

Features

Built for batch work on a single Mac.

Batch any input

Files, directories, or shell globs. Skip existing outputs, or overwrite on re-runs.

Smart chunking

28-second windows aligned to silence so cuts land between sentences, not mid-word.

One sentence per cue

--max-cue-sentences 1 caps each screen to a single sentence; override per run.

Hugging Face cache

Models download once and persist. --local-only hard-fails if cache is missing.

Proxy aware

.env-loaded HTTP/HTTPS proxies, with --check-proxy and --check-network doctors.

uv-managed deps

Reproducible installs via pyproject.toml + uv.lock. One uv sync and you're ready.

Web UI

Run a batch without leaving the browser.

A zero-dependency local web frontend ships with the project. Pick your video folder with the native macOS chooser, hit Run, and watch two progress bars — one for files in the batch, one for the audio inside the current file — alongside elapsed time and an estimated time remaining in minutes or hours.

  • Native folder picker (no path-typing).
  • Saved config in ~/.config/subtitle_anywhere/config.json.
  • Live CLI preview — copy the equivalent terminal command at any time.
  • Per-chunk progress with mm:ss / mm:ss position inside each file.

Quick start

From clone to first SRT in three commands.

1 · Install
# Homebrew
brew install uv ffmpeg
uv sync
2 · Preview
# dry-run, no model load
uv run python server/server.py \
  ~/Videos --dry-run
3 · Generate
# EN audio → bilingual EN/中文 SRT
uv run python server/server.py \
  ~/Videos \
  --target-lang zho

Prefer a GUI? Launch the local web UI with uv run python server/web.py and open http://127.0.0.1:8765.

Output

A clean bilingual SRT, named like the source.

Each cue carries the source line followed by the translated line, with timestamps taken from Whisper's per-segment alignment. Output filenames mirror the source — movie.mp4 becomes movie.zho.srt by default, sitting beside the original so any media player picks it up automatically.

  • Configurable output directory with --output-dir.
  • Skip existing with --skip-existing for safe re-runs.
  • Source-only mode with --no-translate when you just need ASR.

Diagnostics

Verify before you batch.

Five built-in checks cover the entire model-fetch path: proxy, network, model metadata, local cache, and a forced download. Useful for behind-the-firewall setups or air-gapped runs.

--check-proxy HTTP CONNECT support
--check-network Reach Hugging Face
--check-model Model metadata
--model-status Local cache
--download-model Preload weights
