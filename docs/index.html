Subtitle Anywhere

Real-time speech-to-text subtitles with local translation for any browser tab. No API keys, no cloud -- everything runs on your machine.

Features

Fully Local

All processing happens on your machine. No API keys, no subscriptions, no data sent to the cloud.

Real-time Translation

NLLB-200 translates between 200 languages using an INT8 quantized model (~300MB) via CTranslate2.

Auto Language Detection

SenseVoiceSmall automatically detects the spoken language. Just pick your target language and go.

Stereo Audio Preserved

Original audio quality is untouched. ASR runs on a separate 16kHz stream while you hear full stereo.

How to Use

1

Start the server

Install dependencies and launch the WebSocket server. Models download automatically on first run.

cd server && pip install -r requirements.txt && python server.py --device mps
2

Load the extension

Open chrome://extensions, enable Developer mode, click "Load unpacked" and select the extension/ folder.

3

Pick a target language

Click the Subtitle Anywhere icon in Chrome's toolbar. Choose your translation target from the dropdown (or "None" for transcription only).

4

Start capture

Click "Start Capture" on any tab playing video or audio. Subtitles appear as an overlay near the bottom of the video.

Supported Languages

Source language is auto-detected. Pick any target for translation.

English Chinese (中文) Japanese (日本語) Korean (한국어) French German Spanish Portuguese Russian Arabic Hindi Thai Vietnamese Italian
