Subtitle Anywhere

Batch-generate bilingual external subtitles for local media files with FFmpeg and an MLX Whisper plus MLX LLM backend on Apple GPU.

Quick Start

cd server
pip install -r requirements.txt
cd ..
python server/server.py ~/Videos/*.mp4 --source-lang eng --target-lang zho --output-dir subtitles

MLX Backend

python server/server.py movie.mp4 --source-lang eng --target-lang zho --output-dir subtitles

MLX Whisper handles speech recognition. For non-English translation targets, the CLI loads an MLX text translator such as mlx-community/Qwen3-1.7B-4bit.

Model Download

python server/server.py --download-model

Output

The CLI writes .srt files with source text followed by the translated line, for example movie.zho.srt.
