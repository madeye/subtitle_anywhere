## Icons

This directory should contain the following icon files for the extension:

- `icon16.png` - 16x16 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

These can be any PNG images. The extension will work without custom icons (Chrome uses a default puzzle-piece icon).

To generate simple icons, you can use any image editor or an online tool to create a
speech-bubble or subtitle-themed icon at the required sizes.
